# Tenant branding samples

These are original demonstration assets for local tenant-branding tests. They
are not the official Google or Wasabi logos and do not imply an affiliation.

For either organization, upload the matching files in this order:

1. `*-light.svg` as **Logo on light background**.
2. `*-login.svg` as **Sign-in logo**.
3. `*-mark.svg` as **Compact logo mark**.

Each horizontal SVG has a 5:1 viewBox. Each mark SVG has a 1:1 viewBox. The
assets have transparent backgrounds and contain no scripts or external links.
